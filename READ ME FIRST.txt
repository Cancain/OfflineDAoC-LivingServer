OFFLINE DAOC 0.37

This folder is the complete game: client, server, clean world, launcher,
tools and source code. It contains no one else's account, characters or bots.

BEFORE THE FIRST START
Turn on the Windows feature ".NET Framework 3.5 (includes .NET 2.0 and 3.0)":
  1. Start menu, type "Turn Windows features on or off", and open it.
  2. Tick .NET Framework 3.5, click OK, and let Windows install it.
  3. Restart the PC if Windows asks.
The game connector needs it. Everything else (the modern .NET runtime) is
already included in tools\dotnet.

PLAY
1. Keep this whole folder together. Don't run files from inside a ZIP.
2. Double-click START OFFLINE DAOC.cmd.
3. Click START SERVER and wait until the launcher shows RUNNING.
4. Click ENTER REALM. Your own local account is created the first time.
5. Create bots with the buttons on each realm's card in the launcher.
6. To finish: quit the game, click STOP SERVER, and wait for it to save.
Only one Offline DAoC server can run at a time.

EDITION
0.37 has only the original Classic + Shrouded Isles classes.
0.37b includes the custom Hibernian Sluaghbinder class.
The download helper you used chose the edition, and the launcher shows it
(VERSION 0.37 or VERSION 0.37b).

UPDATES
From 0.37 on, new versions come as updates: download the new version's
downloader from its release page, run its GET-OFFLINE-DAOC file and press 1
(Update my game). Only what changed is downloaded; your account, characters,
bots and settings stay. Everything an update replaces is backed up in
patch-backups in this folder (BACKUP.txt there says how to undo it).

THE NEW CLIENT (0.37c)
0.37c is this game (0.37 or 0.37b) with a second, new client added in
new-client.
If this folder has START OFFLINE DAOC - NEW CLIENT.cmd, you have it: read
READ ME - NEW CLIENT.txt. Both clients play the same account, characters and
bots. On 0.37 it offers the classic classes only. To add it to this folder,
run GET-OFFLINE-DAOC-v0.37c.cmd from the 0.37c release page and press 1
(Update my game): it offers to add the new client. See docs\NEW-CLIENT.md.

COMING FROM AN OLDER VERSION?
From 0.36, 0.36b or 0.36c, just update (see UPDATES). From 0.35 or older:
run IMPORT PROGRESS FROM OLD OFFLINE DAOC.cmd and pick your old folder. It
brings over your account, characters, items, money, houses and bots. Your old
folder is not changed, and this folder is backed up first. See
docs\TRANSFER-PROGRESS.md.
